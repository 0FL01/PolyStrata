# Shader measurements on gfx1031

Stock is the **matching local shader**, not vLLM. The runs below used the standard guard and a serial GPU lock. Leaf measurements exclude host routing, CPU experts, staging, page faults and length of a successful trajectory. The donor [source/test map](differential.md) describes what was and wasn't reproduced.

### Attention: move address work, not the donor's LDS layout

Three scratch variants of our packed H2 pipeline: move next tile's load from before QK to after QK; also alias the 4 KiB K/V slabs with barriers; or keep original prefetch timing and compute a wave-uniform physical row base once per fully valid tile. The last uses a conditional wrap and retains the stock edge/seal fallback. Ten deterministic synthetic single visits, seven rounds of graph timing with rotating/reversing arm order, three calls per replay. All three matched stock H2 on **9,102,336 FP32 output words, 718,848 packed Q8_1 bytes and 20,623,200 used workspace floats**. That doesn't make H2 exact relative to FP32 attention: relative L2 vs FP32 was 9.53e−6 to 2.95e−4 in the nine applicable cases.

| H2 case (queries/span) | Stock → scalar tile fetch, ms per visit | Paired time change |
|---|---:|---:|
| Direct SWA ring wrap, 128/8318 | 0.32486 → 0.31062 | −4.37% |
| Staged SWA, 1024/2055 | 1.63488 → 1.60916 | −1.51% |
| Dense Q8 global, 512/32768 | 22.48476 → 22.07330 | −1.97% |
| Compact split V4, 128/65664 | 11.26555 → 11.41887 | **+1.01%** |

Generated shader (`llvm-objdump` on linked objects, TheRock clang 23, wave32): direct stock **175 VGPR, 10,432 B LDS, 5 waves/SIMD**; late load **205 / 10,432 / 4**; shared slab **246 / 6,336 / 4**, 11 vs 7 barrier sites. The supposedly lighter slab regressed all ten cells (0/70 paired wins). Compact VGPR also grew 192→237. Scalar address path kept direct occupancy (**176 VGPR, 5 waves**), despite a larger static instruction stream including fallbacks. No selected variant spilled. All retained the same half2 arithmetic. Do not change the compact V4 dispatch, always-on W1 math or FP32 path based on these results. On a wide append the local attention often uses the contiguous stage, not the ring with the largest isolated percentage. Local files `tiles/{REPORT.md,prototypes.py,bench.cu,build.sh,guard-tiles-02-summary.txt}`.

**Engine result: do not integrate the scalar fetch now.** Replaced only direct Q8 H2 in a scratch Release ELF. Same fresh 8,192-token Tideglass prompt and seed, ABBA: stock/scalar/scalar/stock prompt times **10.074 / 9.974 / 8.149 / 8.045 s**, TTFT **10.075 / 9.975 / 8.150 / 8.046 s**. Scalar was 1.0% faster in AB, 1.3% slower in BA. Every leg exercised 32 global and 160 staged SWA H2 dispatches, not raw-ring SWA. **17/17 greedy IDs matched** across all legs. W1 never ran the candidate; don't assign its variation to this change. No measured near-197K append advantage. Source relink, checked shader identities and launch counts in `tiles/ENGINE.md`.

### Q4 MoE: preserve the dot **and** the final FMA

Archive on the same GPU (mixed/code 64K): Q4 gate/up kernels 2.62/2.65 ms/token, Q4_0 down 1.21/1.28, Q4_1 down ~0.08 and existing fused SiTU/Q8_1 ~0.12. These are kernel sums, not removable wall time. For the leaf, 16 real Tideglass physical layer/expert pairs, matched normalized inputs and the production linked stock GPU kernels. Eight slots per fixture group; five copies in rotating measurements exceed 96 MB Infinity Cache (not a proof of DRAM-cold access). Even identical integer dots **failed** FP32 comparison when the last stock gate/up multiply-add was computed as two separately rounded instructions; Q8_1 and final down happened to match. After restoring FMA, gate/up, quantized SiTU and down outputs matched byte for byte. CPU replay reversing reduction tree order changed thousands of FP32 words and one Q8_1 block. Keep the Q4_0 raw rounded activation-sum correction and Q4_1 min term distinct.

Wave32 same-order DPP ALU replaces `ds_bpermute_b32` without reversing the XOR tree. Q4_0 GU clone: **20** DS permutes → **4** `v_permlanex16_b32` + **16** `v_add_f32_dpp`, 302→248 static instructions, 39 VGPR. Rotating eight-slot complete chain stock → DPP bundle: **114.29→112.98 µs** Q4_0 down, **120.03→117.17 µs** Q4_1 down, 7/7 paired wins each. Compared with the *same contiguous clone*, just the projection DPP saved **1.37/1.72 µs**. The bundle isn't just one change to the production slot ABI. DPP moves *without* the ALU could regress. For an engine experiment substitute only the reduction in the actual pointer slots; the existing `STRATA_INKLING_Q4_0_SLOTS` is the path of interest, not a new contiguously packed bank.

**Engine result: leave existing Q4 slot kernels alone.** Same scratch Release ELF, real 2,048-token code prompt, 160 W1 intervals, live swaps and fixed 4,968 MiB expert/KV budget, AB/BA. **161/161 greedy IDs** and aggregate hits matched all four legs. Mean W1 time change B−A: **+0.187 / −0.087 ms/ID** for AB/BA, p90 **+0.546 / +0.098 ms**. Separate traces confirmed the candidate actually ran (4,530 DPP dispatches over 48 steps, matching shape and slot counts); affected kernel sums **3.923→3.918 ms/step**, about 13% of traced elapsed before the change, not necessarily critical-path exposure. Gate/up's gain nearly canceled Q4_0 down's loss. Do not attribute the contiguous leaf gain to production pointer slots. Exact scratch patch and reproduction in `moe/w1-dpp/{candidate.patch,REPORT.md}`.

On synthetic native-format NVFP4, scale/code layout changes did not justify repacking. Compute sharing was more interesting: per four truly shared rows, gate/up **191.17→86.25 µs**, down **124.06→50.95 µs** vs four single-row jobs. Single-row W1 on this Q4_0 GGUF has no such group. Four-row reuse changes VGPR pressure and only applies if real verified rows reuse an expert, which is not guaranteed at small K. No basis to port half atomics, downcast state, replace quantization or convert the model. Local files `moe/{REPORT.md,run.sh,isa.csv,guarded-real-03/command.log}`.
