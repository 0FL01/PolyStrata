# P2 — Streaming writer fixtures

Parent specification: [P1 transplant plan](transplant-plan.json), H0 `e8a583198523fe1119120061ed68fc3ce14dd1052ef53815014c867b307b9e37`. The [experiment lock](experiment-lock.json) is unchanged; neither the timing executable nor production is part of this diff.

`tools.inkling_weights.transplant build` streams raw payloads in 8 MiB chunks, preserves typed and ordered metadata, and recalculates aligned offsets. The full source scan also hashes each tensor, so a payload changed between that scan and copying cannot be certified as a snapshot of the original. The staged header is checked by the repo's independent `GGUFFile` decoder over bounded bytes; all staged payloads and the whole staged file are hashed. The writer links the validated sidecar first, then publishes the staged GGUF without overwriting any existing path. A publication collision is reported without unlinking a public path. Sources are opened read-only. H1 checks the 32 full RECON payload digests; H2/H3 record the actual copied digests without claiming a full donor-file verification.

`TMPDIR="$WORK" python -B -m unittest -v tools.inkling_weights.test_transplant` passed all seven cases: changed offsets and typed numeric/string arrays, then rejection of duplicate and missing tensors, unsupported types, rows not divisible by their block size, unaligned/overlapping/out-of-bounds spans, truncated data, invalid HTTP responses and attempted output overwrite. The independent review added explicit checks for contradictory response headers, a same-size change to the source after the pinned scan, and concurrent creation of the destination. A bad hash leaves neither staging files nor output. Small fixture directories were removed by their context managers. The stricter HTTP check also reproduced the P1 inventory byte for byte from the real endpoint.

Verdict: **passed on synthetic fixtures**. Next: use the same writer with no replacements for the P3 copy of the actual H0. GPU load/greedy evidence still requires the guard to pass.
