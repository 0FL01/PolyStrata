## Что изменило время успешной задачи

Только пары, в которых оба решения прошли независимую проверку и число ходов одинаково. По каждому turn интервал = `(число ID − 1) × (1/TG)`. Симметричное разложение стоимости в секунды по количеству интервалов и цене интервала. TTFT каждого turn отдельно; residual — инструмент, grading, вывод и накладные расходы измерения. Это бухгалтерское тождество для **наблюдаемых** траекторий, не интервенция и не доказательство причинности. Отсутствие строки для неуспеха не улучшает политику; отказы перечислены в [сводной матрице](scoreboard.md) и [длинных задачах](long-context-tasks.md).
