# CP-01 — serial decode, Tideglass Q4_0, RX 6700 XT

Все шесть длин завершили 256 шагов (257 показанных ID), без драфтов, reuse и остановок guard. Это по одному untraced первому запросу в новом процессе с живыми swaps, одинаковым seed профиля и synthetic length-stress prompt. Не AB, не сравнение разных версий движка. `mixed` на 2K и 4K содержит только prose. На длинных контекстах текст повторяется. Часть CPU RECON выполнялась параллельно; хвосты сохранены. Снимок сохранялся после завершения измерения.

Throughput = 256 / wall seconds от первого до последнего полученного ID. Перцентили — интервалы прихода ID в pipe, не kernel latency. `DONE` учитывает expert hits/misses всего запроса, а не только измеренного окна. `resident_at_load` — число слотов при старте, не после роста KV. На near-cap prompt + 257 ID ровно 200000, последний показанный ID ещё не подан на вход. В boot-журнале один и тот же набор warning-записей не является новыми fault на каждой ноге.
