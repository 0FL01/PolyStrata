# CP-00 — Карта экспериментов Inkling-2-Mini decode на RDNA2

**PASS, реконструкция истории.** Срез Git `c0dd0e52`; ближайший следующий коммит `398027f8` меняет только инструкции guard в `AGENTS.md`. Ни одного нового GPU-прогона. Все числа ниже исторические, на RX 6700 XT (`gfx1031`, 12 GiB, 96 MiB Infinity Cache) / Ryzen 7 5700X, если не оговорено иное. Выигрыши разных раундов не складываются.

## Что считать baseline

- **Разные поколения модели.** `ce9e9b28` / `23f603f4` запускали Unsloth UD-Q4_K_XL. Большинство ранних decode-экспериментов от `90b7ec72` до `e72e40d7` — Unsloth **UD-IQ4_XS**, с NVFP4 experts там, где применимо. `6d7e00d3` добавил `inkling2_loop` и Q4_1 dispatch, сохранив 48 visits и Q8_0 state; `d0b8082e` зафиксировал **Bartowski Q4_0** в качестве нового baseline. На одном `6d7e00d3` Q4_1 → Q4_0: 41.88 → 43.67 t/s (2K), 39.12 → 41.35 (16K), с пересекающимися диапазонами и более высокой perplexity Q4_0 в малом CPU-тесте. Это смена весов, не exact-оптимизация.
- **Исторический контроль Q4_0** — исходный `6d7e00d3` против `7ce0ea6a`, Bartowski, 200K capacity, Q8_0 KV, 2048 MiB reserve, 8 workers, без lookup/DSpark. 2K 47.930 → **51.325**, 4K 46.785 → **49.325**, 16K 44.275 → **47.990**, restored 64K 37.206 → **38.140** t/s. 2K/4K/16K — 320 forced IDs, restored 64K — тот же snapshot + один новый prompt token и 256 greedy IDs. Это не свежий контроль для CP-01.
- **Последнее состояние, доказанное в Git.** `c0dd0e52` оставил оригинальный Bartowski H0 (`Inkling-2-Mini-Q4_0.gguf`, SHA-256 `e8a583198523fe1119120061ed68fc3ce14dd1052ef53815014c867b307b9e37`) на установленном Release `c014d6ec` (SHA-256 `981d969b87193eed0e7b48d329b4816b34142d247e1fcbbad4c95e025d6a642a`). Между ними нет изменений `src/poly`/`src/kernels/cuda`. [Lock](../inkling2-weights/experiment-lock.json) фиксирует Q8_0, 200K, batch 2048, reserve 2048 MiB, 8 workers, 64 swaps, disk sessions, Q4_0 slots/dense и 160 decode chunks; HTTP без DSpark, но `default_lookup: 3`. Стенд H0 был greedy, `--lookup 0 --no-draft`; это не буквально настройки HTTP-запроса. Задание CP-01 называет `Tideglass-Inkling-2-Mini-Unbound-v2.1.gguf`, которого этот lock не удостоверяет. Сверить live model path, hash, types, runtime argv/env и lookup до сравнений; не отождествлять этот путь с H0 или с экспериментальным A1. CP-00 не проверял живой процесс.
- **Более поздний H0 A/A на `c014d6ec`:** у [P5](../inkling2-weights/p5-report.md) 512 frozen IDs, 511 timed steps, warm-ups + `ABBABAAB`. 2K median 44.70 / 44.97 t/s, adjacent deltas −4.10…+7.92%; 16K 43.97 / 43.99, −0.86…+0.67%; median hits ~83% и 84.9%. 2K slow leg совпал с меньшим core clock и большей CPU expert latency, без скачка major faults. Это предупреждение о шуме для конкретных fixtures, не глобальный порог и не регрессия исторических 51.325/47.990.
