### Native implementation checkpoints

- Release HIP worker now has explicit `--dflash2-model`, `--draft-max 0` (loaded W1), and optional `--dflash2-budget-ms`. The target remains the only sampler. Guesses cannot enlarge mapped KV. The verifier uses ordinary W1 placement at the anchor, then applies each actual W1 expert transition after the preceding row is known to be committed. Before sampling any later row it checks the GPU/CPU backend of every routed expert; a changed backend triggers prefix commit and a W1 replay of the already-emitted token with its prepared placement. Batch window state and discarded route counts do not reach SAVE. Bounded host expert pools use W1. RESTORE invalidates draft state and warms on 2,048 newly evaluated rows; target snapshots remain readable by W1. DFlash2 does not yet serialize its own state.
- RX 6700 XT, Ryzen 7 5700X, Tideglass, dense Q8 + compact SWA: the Group4 test matches separate W1 FP32 and Q8_1 outputs, including chunk boundaries. Diagnostic wire pair, matched staged prefill, 1,092 initial experts, 64 swaps, 96 sampled IDs at T=1/seed42: exact FP32 logits, per-position hashes of slot offsets/recency/use, route profile and full SAVE payload. The uninstrumented W1/K3 pair likewise matched IDs and SAVE. A cold unmodified-prefill screen was *not* a valid oracle: two loaded W1 legs first differed at ID 92 and their prompt/answer route counts differed, so the exact A/B fixes prompt staging but leaves **decode** swaps live.
- The initial reject-on-any-trade design offered only three guesses in that live trace. Per-route fallback offered 125, but replayed 36 of 42 rounds: loaded W1 **42.43 tok/s, 29.24 ms** wire ID gap p90; K3 **28.69 tok/s, 64.64 ms**; 65 ms adaptive cost estimate **41.35 tok/s, 29.52 ms** (one draft and one replay). With zero swaps on the same short Python fixture: loaded W1 **30.85 → 44.84 tok/s**, p90 **36.20 → 79.14 ms**, 67/81 guesses accepted, with byte-identical IDs and SAVE. Neither result licenses changing the live service defaults.
- End-to-end wire quant screen with fixed 4,750 MiB expert+KV arena, equal 1,092 initial experts, zero swaps, 8 workers, T=1/seed42, Q4 reuse enabled: Q4_0 led the short reasoning task and tied Q4_0-mixed on the tool prompt; all five DFlash2 files matched installed target IDs/profile in that screen.
